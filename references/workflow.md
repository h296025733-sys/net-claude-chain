# 采购新加坡资源

先在已有登录会话和已授权的资料里核对资源、未付订单、剩余额度和到期时间。ByteVirt VPS 和 CLIProxy 住宅出口都要在新加坡。可用的已有资源直接复用。需要登录或验证码时使用浏览器交接能力，用户交还控制后接着操作。

- ByteVirt 使用[实时库存](https://bytevirt.com/index.php?m=bvstore)或[新加坡线路](https://bytevirt.com/store/sg-china-optimized)。选新加坡、中国优化、月付、可运行 Debian 的 KVM 套餐。检查实时库存、规格、计费周期及金额。
- CLIProxy 使用[长效静态 ISP](https://cliproxy.com/pricing/static-isp/)及[用户后台](https://dash.cliproxy.com/)。选新加坡（SG）、单个、30 天、独享固定的原生住宅出口。确认 SOCKS5、账密认证和有效期开始时间。已有合适额度优先使用，只提取本次需要的一个。
- 两项条件都能满足才准备新购订单。新加坡缺货时在指定商家内核对同地区合格套餐，仍缺货就保留页面告知用户。地区和供应商保持固定。

选品、加购并实际打开显示金额和付款方式的页面。核对商品、地区、数量、应付金额和币种、周期、续费方式。付款按钮、扫码和付款密码交给用户。把可继续的页面留着。用户发「已付」并交还浏览器控制后，核对账单已结清、服务已开通或额度已到账。未支付和待开通的订单接着使用同一订单。

从商家后台核对 VPS 公网地址、SSH 访问方式和到期日，确认代理连接地址、端口、实际出口和到期日。代理连接地址与实际出口分别记录。连接参数使用受保护的文件和商家界面，支付信息、代理密码、私钥及真实配置留在本机。
