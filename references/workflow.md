# 采购新加坡资源

先在已有登录会话和已授权的资料里核对资源、未付订单、剩余额度和到期时间。ByteVirt VPS 和 CLIProxy 住宅出口都要在新加坡。可用的已有资源直接复用。需要登录或验证码时使用浏览器交接能力，用户交还控制后接着操作。

- 缺 VPS 时，Agent 打开 ByteVirt 的[实时库存](https://bytevirt.com/index.php?m=bvstore)，核对[新加坡中国优化](https://bytevirt.com/store/sg-china-optimized)和[新加坡标准 KVM](https://bytevirt.com/store/vps-sg-kvm)。优先选中国优化，同商家可选标准新加坡 KVM。只选有公网 IPv4、支持 Debian、可月付的现货。检查规格、周期和金额。
- 缺住宅代理时，Agent 打开 CLIProxy 的[长效静态 ISP](https://cliproxy.com/pricing/static-isp/)及[用户后台](https://dash.cliproxy.com/)。选新加坡（SG）、单个、30 天、独享固定的原生住宅出口。确认 SOCKS5、账密认证和有效期起点。有合适额度时只提取本次需要的一个。
- 两项条件都能满足才准备新购订单。新加坡缺货时在指定商家内核对同地区合格套餐，仍缺货就保留页面告知用户。地区和供应商保持固定。

## 打开付款页

用可交接的浏览器实际操作。已存在匹配的未付账单时，打开这张账单，继续到付款。否则在 ByteVirt 配置商品并走到结账和账单，在 CLIProxy 选定套餐、地区和数量并走到支付方式页面。

交接前核对商品、地区、数量、应付金额和币种、周期、续费方式。目标是用户能扫码或点击付款的收银台。若下一步会直接扣款、消耗已存余额或提交有约束力的订单，就把该确认页交给用户。需要登录、验证码或同意条款时，先交接当前页面，用户交还控制后从原处继续。保留付款页和订单位置，使用工具支持的交接功能。

## 付款后继续

- 用户可用另一台设备扫码且 Agent 仍可操作浏览器时，保留付款页，用商家订单或服务页面只读检查账单状态，避免刷新正在使用的收银台。
- 浏览器要求用户接管时，先交接。用户交还控制后自动回到商家账单核对同一个订单，无需另发「已付」。平台暂未返回控制时保留待付款位置，由恢复事件继续。
- 待付款或待开通时，保留同一个订单并继续检查。遇到页面停用或订单过期，说明对应商家和订单状态。到账且服务已开通（或额度已到账并可提取）后，直接进入[部署流程](deployment.md)。

从商家后台核对 VPS 公网地址、SSH 访问方式和到期日，确认代理连接地址、端口、实际出口和到期日。代理连接地址与实际出口分别记录。支付信息、连接凭据及真实配置留在受保护的本机文件里。
