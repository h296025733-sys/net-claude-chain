# 实际验收

默认验收在后台执行。用户需要使用时，从 Windows 桌面的 `Claude 专用网络` 文件夹手动双击快捷方式。桌面重定向到 OneDrive 时，使用 Windows 返回的桌面位置。

1. 核对专用代理的 Windows 开机任务和运行状态。使用明确指定环回 HTTP 代理的请求访问 `https://api.ipify.org`，确认出口与 CLIProxy 已核实的住宅 IP 一致。若本机另有 VPN，检查 VPS 路由仍通过物理网卡。
2. 核对三条快捷方式分别指向 `Web`、`Desktop`、`Check`。后台校验浏览器路径、独立资料目录、官方 Claude Desktop 安装包以及桌面端专用防火墙规则。
3. 检查代理任务 `NetClaudeChain-Proxy`，复用代理时检查 `NetClaudeChain-Route` 和原代理任务。开机和进程恢复只适用于专用代理。核对旧版 `NetClaudeChain-Desktop` 启动任务已停用或移除。
4. 用户要求实测应用窗口时，才打开指定入口。用户关闭窗口后，确认窗口保持关闭且后台代理继续工作。若实际打开了检测入口，核对 Net.Coffee 的出口、地区、网络类型和当时的评分。如截图会发给用户，裁掉或遮挡凭据、私人信息和完整订单标识。

交付时写明快捷方式的位置、实际做过的验证，以及桌面端是复用、安装、修复还是重装。有备份时告知本机保存位置。
